# AIRON Native — Private AI That Learns Locally

Use a fresh provisioned state and the local console. Present only the observed results in STATUS.md and the displayed workspace. This is an experimental demonstration using synthetic material.

| Scene | Operator action | Evidence to show |
|---|---|---|
| Deploy | Connect with operator token; inspect original model | Pinned pretrained model, local deployment version |
| Understand | Ask “When should we inspect the cooling assembly?” | Local generation; exact-source validation or explicit abstention |
| Protect | Ask “Who approves large supplier payments?” and an unsupported question | Denial/abstention before the model is called |
| Identify limitation | Run the frozen benchmark | Baseline predictions and six routing cases |
| Adapt | Train the prepared authorised synthetic dataset | Genuine Soup LoRA job, steps, changed tensors and measured runtime |
| Verify | Register candidate and compare | Same frozen routing and regression suites; exact counts, not a broad quality claim |
| Authorise | Request review; inspect digest/results; use reviewer token | Distinct local session role and explicit approval |
| Activate | Activate candidate, run inference and approved document query | Versioned local adapter; source validation remains enforced |
| Prove isolation | Show the separately executed isolated acceptance and trace audit | Fresh offline install, namespaces, failed deliberate probes, classified syscall trace |
| Inspect and restore | Verify records with approved key/head, then restore original model | Application signatures, original model pointer and restored predictions |

Suggested narration: “The private documents stay on this machine. The model can be adapted here, but a training process cannot put its own result into service. We compare a candidate, review the evidence, approve a version and retain the original model for rollback.”

Explain the evidence level plainly: these are signed application records and an external syscall trace from the tested runner. AIP/Sniffer Dog, independent key custody and customer-site qualification remain separate gates.

Do not present closed-choice routing scores as general reasoning, AGI or unconstrained answer accuracy. Do not hide an abstained document answer, a failed evaluation or an incomplete offline run. Do not use a scripted test reviewer as proof of an independent human reviewer.
